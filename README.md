# CreateMint

Сборка Minecraft **1.21.1** на NeoForge: Create с аддонами, своя генерация мира (ReTerraForged)
и дальняя прорисовка Distant Horizons.

## Как играть

Скачайте лаунчер **[Mint](https://github.com/GrayRK/MintLauncher)**, выберите сборку CreateMint
и нажмите «Играть» — моды, конфиги и Java установятся сами. Ставить что-либо вручную не нужно.

## Что лежит в этом репозитории

Только то, что должно быть одинаковым у всех игроков:

| | |
|---|---|
| `instance.json` | версия игры и загрузчика |
| `mint-pack.json` | список модов: ссылки, sha1 и сторона (`CLIENT` / `SERVER` / `BOTH`) |
| `config/`, `options.txt` | настройки модов и игры по умолчанию |
| `MODPACK.md` | журнал сборки: что, зачем и с какими последствиями менялось |

Сами моды здесь не хранятся — лаунчер качает их с Modrinth по ссылкам из `mint-pack.json`.

## Сервер

Лаунчер умеет поднимать сервер этой сборки кнопкой «Сервер»: он ставит NeoForge, переносит конфиги
и берёт только те моды, что помечены `BOTH` или `SERVER`. Друзья подключаются через ProximaTunnel,
без проброса портов и без установки чего-либо со своей стороны.
